# trioTE — 出差報銷懶人系統

Trio 專用報銷懶人系統。純前端網頁，架在 GitHub Pages 上，所有資料（含發票圖片）只儲存在瀏覽器本地端（localStorage + IndexedDB），**不會上傳到任何異地伺服器**；只有你按「Google Drive 預覽」時，才會把匯出的 Excel 上傳到你自己的 Google Drive。

## 功能

- **匯率表**：預設 NTD / RMB / USD / THB / HKD，可自行增列幣別；台幣(NTD) 固定 1:1。修改匯率時，還在用舊匯率的明細會一起更新（手動改過匯率的不動）。
- **上傳發票**：上傳圖片或 PDF（每頁自動轉圖片），也可 Ctrl+V 貼上 → 自動偵測發票區塊（白底掃描/電子發票整張一框；照片中多張發票各自框出）→ 不對可按「✂ 手動裁切」或「整張」→ 即時預覽。
- **自動辨識**：瀏覽器內建 OCR（Tesseract.js）+ 規則，自動判別金額、幣別、日期、類別（交通／住宿／膳食），可手動修正。幣別：先看明確字樣（NT$、¥、人民币、HK$、฿、USD），否則看文字——繁體→台幣、簡體→人民幣、泰文→泰銖、純英文→美元。
- **類別**：內建交通／住宿／膳食／其他／交際費，可自行建立類別並將發票移動到該類別。交際費會匯出到範本下方的「交際費」區塊（沒有交際費就不產生）。
- **每日上限**：以台幣計算每日膳食上限（預設 600 元），超限會標紅並在匯出時自動扣回。
- **核銷明細**：自動生成「開始日期／結束日期（住宿、機票等跨日可填結束日期）／消費方式／幣別／適用匯率／交通費／膳食費／住宿費／其他費用／本幣合計」明細，金額、日期、幣別、類別皆可改。
- **匯出 Excel**（ExcelJS）：樣式逐格取自公司範本（`template-spec.js`）——標楷體字型、雙線外框、灰底標題、淺黃公式格、列高欄寬、合併儲存格、會計數字格式、A4 列印設定；適用匯率／本幣合計／合計天數／幣別彙總寫成範本同款公式，消費方式、幣別有下拉選單；主表的膳食同幣別合併成一列（明細見膳食費憑證），超限扣回合併成一列；補充說明依範本格式自動產生（差旅費、交際費、預支扣款、實付請款金額）。分頁照公司範本：出差費用種類、1. 匯率表輸入、2. 出差報告暨旅費核銷明細表、出差日報及交際費明細、交通費憑證、住宿費憑證、膳食費憑證（依日期的膳食明細表格，含每日小計與超限扣回）、膳食費發票（膳食發票照片）、通訊費憑證、其他憑證拍照或掃瞄；憑證/照片頁有資料才產生。匯出後資料仍在本地端不消失。
- **公司已訂機票**：核銷明細按「✈ 新增公司已訂機票」，列在旅費明細交通費；補充說明自動以「已預付來回機票款」扣除。
- **預覽報表**：匯出前先在網頁上看到跟 Excel 一樣的主表（明細、各幣別加總、補充說明、交際費）與膳食費憑證，方便核對。
- **Google Drive 預覽**：把同一份 Excel 上傳到自己的 Google Drive，用 Google 試算表開啟；同一份報帳再上傳會更新同一個檔案。權限只有 drive.file（只能存取本系統上傳的檔案）。第一次使用需建立 Google OAuth 用戶端 ID（網頁上有步驟說明），也可直接填在 app.js 的 `GOOGLE_CLIENT_ID` 全公司共用。
- **清除**：一鍵全清、個別刪除。

## 本地開啟

直接在瀏覽器開啟 `index.html`，或：

```bash
python -m http.server 8765
# 開啟 http://localhost:8765
```

## 部署到 GitHub Pages

1. 將此 repo 推上 GitHub。
2. Repo → Settings → Pages → 來源選 `main` 分支、根目錄 `/`（或 `docs`）。
3. 等部署完成，網址為 `https://<你的帳號>.github.io/trioTE/`。

## 公司範本改版時

範本樣式存在 `template-spec.js`，由腳本從公司範本自動產生：

```bash
pip install openpyxl
python tools/extract_template_spec.py "樣本-出差報告暨旅費核銷.xlsx"
```

腳本只抽樣式與固定標籤文字，不會把範本裡的範例資料帶進來。

## 已知限制（MVP）

- 純前端 OCR（Tesseract.js）對中文發票字樣／手寫的辨識準確度有限，金額較可靠，幣別／日期靠規則推斷，建議辨識後再人工確認。
- 匯出需要網路載入 ExcelJS（cdnjs）。
- 信用卡消費：本幣合計寫入「刷卡金額 × 明細上的適用匯率」，適用匯率欄用範本的反推公式；請把明細上的匯率改成帳單實際匯率。
- 住宿超限（大陸每日 2,200）尚未自動扣回，目前只自動扣膳食超限。
- 「出差日報及交際費明細」依出差期間每天一列並自動帶入交際費；客戶、產品、樣品數量等欄位請手動填寫。
