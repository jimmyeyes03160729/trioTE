# trioTE — 出差報銷懶人系統

Trio 專用報銷懶人系統。純前端網頁，架在 GitHub Pages 上，所有資料（含發票圖片）只儲存在瀏覽器本地端（localStorage + IndexedDB），**不會上傳到任何異地伺服器**。

## 功能

- **匯率表**：預設 NTD / RMB / USD / THB / HKD，可自行增列幣別；台幣(NTD) 固定 1:1。
- **上傳發票**：上傳圖片 → 自動偵測發票區塊（一張照片多張發票也會框出）→ 可手動拖框裁切 → 即時預覽。
- **自動辨識**：瀏覽器內建 OCR（Tesseract.js）+ 規則，自動判別金額、幣別、日期、類別（交通／住宿／膳食），可手動修正。
- **類別**：內建交通／住宿／膳食／其他，可自行建立類別並將發票移動到該類別。
- **每日上限**：以台幣計算每日膳食上限（預設 600 元），超限會標紅並在匯出時自動扣回。
- **核銷明細**：自動生成「開始日期／結束日期／消費方式／幣別／適用匯率／交通費／膳食費／住宿費／其他費用／本幣合計」明細，金額、日期、幣別、類別皆可改。
- **匯出 Excel**：格式對齊範本，匯出後資料仍在本地端不消失。
- **清除**：一鍵全清、個別刪除。

## 本地開啟

直接在瀏覽器開啟 `index.html`，或：

```bash
python -m http.server 8765
# 開啟 http://localhost:8765
```

## 部署到 GitHub Pages

1. 將此 repo 推上 GitHub。
2. Repo → Settings → Pages → 來源選 `main` 分支、根目錄 `/`（或 `docs`）。
3. 等部署完成，網址為 `https://<你的帳號>.github.io/trioTE/`。

## 已知限制（MVP）

- 純前端 OCR（Tesseract.js）對中文發票字樣／手寫的辨識準確度有限，金額較可靠，幣別／日期靠規則推斷，建議辨識後再人工確認。
- 匯出 Excel 的「膳食每日分頁」會嘗試嵌入發票圖片；受 SheetJS 免費版限制，非膳食類別發票圖片可能未嵌入，但資料與圖片仍完整保留在本地端。
- 信用卡消費的「適用匯率」目前以匯率表查表值呈現（範本中信用卡為反推公式，可於匯出後手動調整）。
