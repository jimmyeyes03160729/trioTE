Google Drive 預覽

第一次使用要先建立 Google 登入用的「OAuth 用戶端 ID」（免費，只要做一次）：

  1. 到 Google Cloud Console 建立一個專案。
  2. 「API 和服務 → 程式庫」搜尋 Google Drive API 並啟用。
  3. 「OAuth 同意畫面」選「外部」，填好名稱與 Email；「測試使用者」加入你自己的 Gmail。
  4. 「憑證 → 建立憑證 → OAuth 用戶端 ID」，類型選「網頁應用程式」，
    「已授權的 JavaScript 來源」填：
  5. 把產生的「用戶端 ID」貼到下面儲存。

本系統只會取得「自己上傳的檔案」的權限（drive.file），看不到你 Drive 裡的其他檔案。
